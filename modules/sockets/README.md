# Модуль Sockets

WebSocket-сервер на Socket.IO. Модуль наследуется от API, поэтому часть архитектуры (создание событий, конфигурация) аналогична.

## Файл конфигурации

| Параметр | Тип | Описание |
|---|---|---|
| `port` | `number` | Порт сервера |
| `paths.events` | `string` | Директория с обработчиками событий |

## SSL

SSL-сертификаты управляются модулем [SSL](../ssl/). Если SSL-модуль предоставляет credentials, сервер запускается по HTTPS, иначе — по HTTP.

## Создание событий

Процесс создания аналогичен методам API. Создайте каталог с именем события внутри соответствующей ветки, добавьте `index.js` и `config.json`.

### Ветки событий

| Ветка | Описание |
|---|---|
| `events/io/` | События серверного уровня (например, `connection`) |
| `events/socket/` | События сокет-уровня (обрабатываются для каждого подключения) |

### config.json события

```json
{
    "use": true,
    "params": []
}
```

Формат параметров идентичен API-методам, за исключением поля `method`.

### index.js события

В метод `getResponse` передается экземпляр сокета (для `io`) или данные от клиента (для `socket`).
